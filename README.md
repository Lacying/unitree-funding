# UNITREE 资金费对比

Hyperliquid 上同名合约的逐小时资金费率、净费率和收盘价差对比，默认查看 para:UNITREE 与 xyz:UNITREE。可选择币种、多空市场以及 4 小时、1 天、7 天、30 天区间。
